投屏窗口快捷键参考

⌨️ 投屏窗口快捷键

以下快捷键作用于 scrcpy 投屏窗口（键盘焦点在投屏窗口上时）。MOD 为修饰键，默认是左 Alt 或左 Super（即 Win 键），可用启动参数 --shortcut-mod 修改（可选 lctrl / rctrl / lalt / ralt / lsuper / rsuper，如 scrcpy --shortcut-mod=rctrl）。

🖥️ 窗口控制

退出投屏MOD+Q
全屏切换MOD+F 或 F11
画面左旋转MOD+←
画面右旋转MOD+→
水平翻转MOD+Shift+←/→
垂直翻转MOD+Shift+↑/↓
暂停 / 重新暂停显示MOD+Z
恢复显示MOD+Shift+Z
重置视频捕获/编码MOD+Shift+R
窗口调为 1:1 像素MOD+G
去除黑边MOD+W 或 双击黑边
FPS 计数器开关MOD+I

📱 设备按键

主页 HOMEMOD+H 或 鼠标中键
返回 BACKMOD+B / MOD+Backspace / 右键
应用切换MOD+S 或 鼠标第 4 键
菜单 MENU（解锁屏）MOD+M
音量 +MOD+↑
音量 −MOD+↓
电源键MOD+P
开机屏幕关闭时按右键

🔆 屏幕与面板

关闭设备屏幕（保持投屏）MOD+O
点亮设备屏幕MOD+Shift+O
旋转设备屏幕MOD+R
展开通知面板MOD+N 或 鼠标第 5 键
展开设置面板MOD+NN 或 双击第 5 键
收起面板MOD+Shift+N

📋 剪贴板 Android ≥ 7

复制设备内容到电脑MOD+C
剪切到剪贴板MOD+X
同步剪贴板并粘贴MOD+V
注入电脑剪贴板文本MOD+Shift+V

🖱️ 手势与其他

捏合缩放 / 旋转Ctrl+点击并拖动
垂直倾斜（双指滑动）Shift+点击并拖动
水平倾斜（双指滑动）Ctrl+Shift+点击并拖动
键盘设置（仅 HID 键盘）MOD+K
拖入 APK 文件直接安装到设备
拖入其他文件推送到设备存储

📷 相机模式

打开手电筒MOD+T
关闭手电筒MOD+Shift+T
相机放大MOD+↑
相机缩小MOD+↓

💡 重复键操作：以「展开设置面板」为例——按住 MOD 不松，连续按两次 N，再松开 MOD。

💡 所有 Ctrl+按键 组合都会直接转发给设备，由设备上当前应用处理。
